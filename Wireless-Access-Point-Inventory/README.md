# 📡 Wireless Access Point Inventory & Asset Tracking

## Overview
Assisted with inventory management and documentation of Ubiquiti UniFi wireless access points.

## Tasks Performed
- Labeled wireless access points for identification
- Recorded and documented device information
- Tracked wireless access points in inventory
- Organized devices to maintain accurate asset records
- Verified devices against inventory documentation

## Result
Wireless access points were properly labeled, documented, and accounted for, improving device organization and asset tracking.

## Key Takeaway
Gained hands-on experience with IT asset management, hardware identification, inventory tracking, and enterprise wireless networking equipment.
